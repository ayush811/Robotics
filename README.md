## Obstacle Avoiding Robot

Built in 2020. Still one of my favorite projects, it's where I first got hooked on hardware-software integration.

### What it does

An autonomous robot that navigates a space and avoids obstacles in real time, using an ultrasonic sensor to detect objects in its path and adjust direction accordingly.

### What I built

- Designed and assembled the robot from scratch on an Arduino platform
- Integrated an HC-SR04 ultrasonic sensor for distance sensing
- Wrote the control logic to interpret sensor readings and trigger obstacle avoidance maneuvers (stop, reverse, turn) based on distance thresholds
- Wired and tested the motor driver circuit to translate control signals into movement
- Debugged sensor noise and timing issues to get reliable, real-time obstacle detection

### Why this project

This was a solo build end to end: mechanical assembly, sensor integration, and code. It's the project that pulled me toward robotics and hardware-software systems, where multiple domains (sensing, control logic, mechanical movement) have to work together in real time.

## Soft Gripper for Humanoid Robots

Built during a Hardware Intern role at Indro Robotech, Mumbai (Dec 2019 to Mar 2020).

### What it does

A soft, silicone-based gripper designed to grip general and irregular object geometries, built for use on a humanoid robot platform.

### What I built

- Designed the gripper through iterative SolidWorks modeling across multiple geometry revisions
- Fabricated molds and fixtures using 3D printing, CNC machining, and laser cutting
- Cast the gripper itself in silicone/elastomer for compliant, adaptive grip on irregular shapes
- Iterated on design based on grip testing across varied object geometries
- Improved grip success rate by 38% across tested geometries compared to earlier design iterations
